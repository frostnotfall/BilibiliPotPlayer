# BilibiliPotPlayer 配置工具

使用 C++17 与 Win32 原生控件实现的独立 x64 程序，适用于 Windows 10/11。
静态链接 MSVC 运行库，只动态依赖 Windows 自带 DLL；不需要浏览器、.NET、Python 或额外安装运行库。

## 使用

成品位于 `Extension/Media/PlayParse/Bilibili_Config_Editor.exe`，与配置文件一起放在
PotPlayer 的 `Extension\Media\PlayParse` 目录，双击即可读取同目录的 `Bilibili_Config.json`。
也可以将配置文件拖到 EXE 上，或使用“打开…”选择其他配置。

- 六个主标签覆盖当前配置中的 52 个有效配置项，提供中文说明、数值校验和错误定位。
- “字幕与弹幕”包含“字幕与样式、字体效果、弹幕过滤”三个分组，共用右侧效果示例。
- 字体从本机已安装字体中选择，字号使用常用数值下拉列表；旧配置中的其他值保留为当前项，不强制改写。
- 鼠标位于滑块上时，滚轮仍用于滚动设置页，不改变滑块数值；滑块支持拖动、点击和方向键调整。
- 字体、字号及其他下拉框收起时，滚轮只滚动设置页，不改变选项；展开后可用滚轮浏览列表，方向键选择不受影响。
- 示例展示五种字体效果对照，并演示顶部/底部/彩色弹幕屏蔽、重复合并、关键词与 UID 屏蔽。功能未开启时仍可预览样式。
- 本地屏蔽规则按“关键词、JavaScript 正则、用户 UID”分为三个多行文本框，每行一条；保存时自动生成 `type`、`filter` 数组。
- 直播的快速模式与快速解析域名位于同一组。
- 直播聊天方式为“不显示、官方网页、自建弹幕姬”三个互斥单选项；只有选择自建服务时才启用地址输入框。配置仍使用原来的两个布尔字段，旧配置同时开启时按脚本原有优先级显示自建服务。
- “初始化全部配置”生成完整推荐默认配置，“初始化本页”只恢复当前主标签的默认值（含其全部分组），均需点击“应用”或“确定”才写入文件。
- 缺少配置文件时，可直接通过“初始化全部配置”创建。全部或分页初始化均在原文件上恢复对应配置项的默认值，保留所有原有注释及未管理字段。
- “应用”保存并保留窗口，“确定”保存并关闭，“取消”丢弃未保存修改并关闭。
- `Ctrl+S` 保存，`Ctrl+O` 打开；关闭窗口时可选择保存或放弃未保存修改。
- 保存后重新加载插件或重启 PotPlayer，使设置生效。

文件支持 UTF-8（含 BOM）、`//` 和 `/* */` 注释。只替换修改过的字段值，保留其他字段、
外围注释、原有换行格式和 BOM；修改列表内容时会重新序列化该列表。列表内部的注释也会保留，被删除条目中的注释移到新列表开头；值不变时保留原始字节。
缺省配置项按脚本默认值展示，普通编辑仅在修改后写入；分页初始化补全本页配置项。
全部初始化使用发行配置的推荐默认值，含 32 号弹幕字体、0.85 不透明度、启用网页评论区、直播分区最大 100 房间和内置的两个快速解析域名。
旧版 CSRF Token 已从界面、发行配置与新建默认配置中移除；编辑或初始化旧文件时仍保留原有兼容字段。
不接受重复键、尾随逗号、无效 UTF-8 和超过 64 层的嵌套；解析错误会显示行列位置。

保存直接覆盖打开的配置，不检测外部变更、不生成备份。先在同目录完整写入并刷新临时文件，
再通过 `ReplaceFileW` 替换原文件；写入失败会报告错误并保留窗口中的编辑内容。
配置所在目录需要有写入权限，程序不自动请求管理员权限。

## 构建与验证

需要 Visual Studio 的 C++ x64 工具与 Windows SDK：

```powershell
.\Native\BilibiliConfig\build.ps1
```

脚本使用 `/O2 /MT /W4` 构建发布 EXE，同时运行配置测试和隐藏的原生 UI 测试。
如需先构建到其他位置，可加 `-OutputExe C:\path\Bilibili_Config_Editor.exe`；运行中的正式 EXE 需先关闭才能替换。
当前成品约 360 KiB，最终大小以本地构建结果为准。
构建和测试中间文件均放在本目录的 `build/`，不会修改真实配置文件。

验证范围：

- 当前配置的全部字段均存在对应控件，默认值可读取与校验。
- JSON 语法、注释、中文与表情、Unicode 转义、BOM、CRLF、未知字段、嵌套项插入。
- 单项编辑只替换对应字节区间；未修改文件逐字节保持一致。
- 数值范围、整数、编码顺序、服务器地址、域名列表、屏蔽规则校验。
- 文件覆盖、只读文件及文件占用时的失败处理，不生成备份。
- 六个主标签及三个弹幕分组、系统字体枚举、字体/字号选择、三类规则的多行文本转换、保存读回、滚动、100%/150%/200% 布局。
- 两个滑块在有焦点、无焦点时均将滚轮交给页面，数值和未保存状态不变，方向键调整仍有效。
- 所有下拉框在有焦点、无焦点时，收起状态的滚轮均交给页面，选项和未保存状态不变，方向键选择仍有效。
- 直播聊天单选项互斥、服务地址启用状态，以及旧配置中两个开关同时开启时的兼容显示。
- 全部初始化、分页初始化的作用范围、稀疏配置补全、缺失文件创建，以及文件头尾、行内、列表内部和重复注释的保留。
- 五种字体效果的像素差异，以及关键词、UID、JavaScript 正则和弹幕类型屏蔽示例。

UI 测试使用 `tests.cpp` 生成的独立配置副本；其中的窗口绘制截图仅供开发检查，
不会随正式 EXE 分发。正式程序不包含测试入口，不访问网络。
正则示例可选用同一插件随附的 `Extension/Lib/BilibiliRegex.dll`；缺少该 DLL 时其余功能正常，界面会标明正则示例不可用。示例最多测试前 16 条正则，并不替代实际播放过滤。
字体效果使用 GDI 示意，实际字幕/弹幕以 PotPlayer 的 ASS 渲染效果为准。
